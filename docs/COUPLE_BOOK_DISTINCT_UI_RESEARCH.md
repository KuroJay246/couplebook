# Couple Book Distinct UI Research

Last updated: 2026-08-22

This file records the practical principles used in the distinct-identity implementation. It is not a broad open-ended research brief.

## Practical Principles Applied

- content first
- predictable navigation
- semantic color tokens
- restrained interface chrome
- editorial memory presentation
- media-first storytelling
- purposeful motion
- recurring couple interaction
- accessible adaptive layout

## Reference Influence, Not Copying

The current implementation draws practical guidance from Apple Human Interface Guidelines, Material 3 token discipline, and consumer journaling references such as Day One, Apple Journal, and Paired. The app does not copy those products' visuals or Event Hub's product identity.
